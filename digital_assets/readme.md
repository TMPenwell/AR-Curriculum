# ReadMe
## Digital Assets

Original artwork created for this curriculum. Free to use.

### Mothman

Located in `digital_assets/mothman/`


All files are transparent PNGs, ready to drop into Lens Studio as an Image
or Screen Image.

**Usage:** Free to use, modify, and share, including commercially. Credit
appreciated but not required — "Mothman artwork by Tasha Penwell" if you'd
like to.

**Provenance:** Original artwork. Not derived from any film, game, or
licensed depiction of the character. The design draws on eyewitness accounts
from Point Pleasant, West Virginia, where sightings were reported between
November 1966 and December 1967.
